Pengelolaan konten dilakukan lewat Google Drive & Google Sheets memakai akun Google resmi PBJ, tanpa server dan tanpa login tambahan. Keamanannya mengikuti akun Google itu sendiri: hanya yang punya akses edit yang bisa mengubah konten.

Panduan Isi Data

Klik judul di bawah untuk buka petunjuknya. Semua bisa dikerjakan langsung di Google Sheets / Drive lewat tombol di atas — tidak perlu ubah kode apa pun, dan perubahan tampil otomatis di website (biasanya dalam hitungan detik sampai beberapa menit, cukup refresh halaman).

Catatan: sejak Juli 2026, kartu "Kelola Event" dan "Kelola Galeri Per Latihan" di atas, PLUS tombol buka/tutup pendaftaran & ganti nomor WA di dalam accordion panduan di bawah, semuanya membuka SATU file Google Sheet yang sama ("PBJ - Pengaturan Situs") — bedanya cuma TAB yang aktif. Jangan pindahkan urutan tab di spreadsheet itu (klik-tahan lalu geser tab) — website mengandalkan tab tertentu lewat ID internal (gid), bukan urutan/posisi, tapi tetap sebaiknya urutan tab dibiarkan apa adanya supaya tidak membingungkan saat isi data.

Cara isi data Event & Race

Buka lewat kartu "Kelola Event" di atas. Satu baris sheet = satu kartu event di website. Baris pertama (judul kolom) JANGAN diubah/dihapus.

KolomIsi dengan
NamaNama event. WAJIB diisi — baris tanpa Nama dianggap kosong & tidak tampil.
TanggalBebas format asal jelas, mis. Minggu, 20 September 2026 atau 2026-09-20.
LokasiNama tempat, mis. JIEP Pulomas, Jakarta Timur.
KategoriLabel bebas yang tampil di kartu, mis. Race, Fun Race, Latber Akbar.
DeskripsiKalimat singkat tentang event (boleh kosong).
LinkInfoLink poster/pendaftaran (boleh kosong). Boleh tanpa https:// asal berupa alamat web, mis. bit.ly/daftar-funrace — otomatis dilengkapi.
LinkMediaLink foto/video event (boleh kosong): folder Drive, ATAU link postingan Instagram (instagram.com/p/...) supaya muncul sebagai popup foto langsung di website.
StatusKetik persis upcoming (akan datang) atau selesai. Selain dua kata itu (mis. salah ketik) dianggap "akan datang" — besar/kecil huruf tidak masalah.

Urutan tampil otomatis: tanggal terbaru paling depan. Kalau ada beberapa event bertanggal SAMA, yang statusnya upcoming didahulukan dari yang selesai — jadi cukup ganti Status jadi selesai setelah event lewat, tidak perlu pindah-pindah baris.

Contoh satu baris: Fun Race Pulomas Cup | Minggu, 20 September 2026 | JIEP Pulomas, Jakarta Timur | Fun Race | Race santai untuk semua member | bit.ly/daftar-funrace | https://drive.google.com/drive/folders/xxxxx | upcoming

Event sudah lewat? Cukup ubah kolom Status jadi selesai — tidak perlu dihapus. Mau menghapus event? Hapus barisnya langsung (klik kanan nomor baris → Delete row).

Cara isi data Galeri Per Latihan

Buka lewat kartu "Kelola Galeri Per Latihan" di atas. Dipakai untuk dokumentasi per sesi latihan yang fotonya ada di Drive PRIBADI tiap fotografer (bukan Drive PBJ) — website hanya menautkan link-nya, bukan menampilkan fotonya langsung.

KolomIsi dengan
TanggalSebaiknya format YYYY-MM-DD (mis. 2026-07-14) supaya rapi & konsisten, tapi format Indonesia seperti Minggu, 14 Juli 2026 juga tetap terbaca & terurut dengan benar.
SesiNama sesi bebas, mis. Latihan Pagi, Latihan Minggu, atau Race Day.
FotograferNama fotografer/pemilik folder — jadi tulisan di tombol kartu.
LinkDriveLink folder Drive fotografer tsb. WAJIB diawali https:// persis (beda dari LinkInfo/LinkMedia di sheet Event) — biasanya sudah otomatis begitu kalau disalin lewat tombol "Bagikan / Share" di Drive.

Satu sesi, banyak fotografer? Isi beberapa baris dengan Tanggal + Sesi yang SAMA PERSIS (termasuk besar/kecil huruf & spasi), beda hanya di Fotografer & LinkDrive — website otomatis menggabungkannya jadi satu kartu berisi satu tombol per fotografer.

Urutan tampil otomatis: tanggal terbaru paling kiri/atas — tidak perlu diurutkan manual di sheet.

Contoh 2 baris untuk sesi yang sama (2 fotografer):
2026-07-14 | Latihan Pagi | Ayah Zeryl | https://drive.google.com/drive/folders/aaaa
2026-07-14 | Latihan Pagi | Ayah Zeryl | https://drive.google.com/drive/folders/bbbb

Pastikan folder Drive fotografer sudah dibagikan minimal "Siapa saja yang memiliki link: Pelihat" — kalau masih dibatasi, orang yang klik tombolnya di website akan diminta izin akses.

Cara upload & kasih nama foto/video (Galeri Kategori)

Buka lewat kartu "Kelola Galeri Kategori" di atas. Masuk ke subfolder yang sesuai (mis. Latihan, Race, Prestasi), lalu upload foto/video ke situ. Mau bikin kategori baru? Buat subfolder baru dengan nama kategorinya — otomatis jadi tombol filter baru di website, tidak perlu lapor developer.

Cara kasih nama file yang bagus

Nama file OTOMATIS jadi tulisan caption di bawah foto di website (tanda - dan _ berubah jadi spasi, huruf besar/kecil ikut nama file apa adanya). Jadi:

  • Pakai nama yang jelas & deskriptif, tanda hubung - sebagai pemisah kata: latihan-minggu-start-gate.jpg → tampil sebagai "latihan minggu start gate".
  • Hindari nama bawaan kamera/HP seperti IMG_1234.jpg atau VID_5678.mp4 — captionnya jadi tidak enak dibaca ("img 1234").
  • Tidak perlu kasih angka urutan di depan nama file untuk mengatur urutan tampil — website otomatis mengurutkan dari yang PALING BARU DI-UPLOAD, bukan dari nama file.
  • Mau caption khusus TANPA mengubah nama file aslinya? Klik kanan file di Drive → Info file → isi kolom Deskripsi. Kalau kolom ini diisi, dipakai duluan (nama file diabaikan).
Contoh nama file bagus: fun-race-jis-4-podium-kelas-2021.jpg
Contoh nama file kurang bagus: IMG_20260712_0931.jpg
Cara buka/tutup Pendaftaran Member Baru

Sheet ini berisi DUA baris pengaturan (bukan daftar seperti Event/Galeri):

Key (JANGAN diubah)Isi Value dengan
REGISTRATION_OPENKetik persis TRUE untuk BUKA pendaftaran, atau FALSE untuk TUTUP.
REGISTRATION_FORM_URLLink publik Google Form (tombol Send/Kirim di Form → ikon link → Salin). Ganti sel ini kapan pun form diganti/dibuat ulang.
Contoh 2 baris:
REGISTRATION_OPEN | TRUE
REGISTRATION_FORM_URL | https://docs.google.com/forms/d/e/xxxxx/viewform

Begitu REGISTRATION_OPEN diubah jadi TRUE, dalam beberapa menit (cukup refresh halaman) tombol "Daftar Trial Class" di navbar, link footer & jawaban FAQ "Masih open member?" otomatis berubah jadi mengarahkan calon member ke halaman Daftar Member Baru (isi Google Form dari REGISTRATION_FORM_URL). Ubah lagi jadi FALSE setelah kuota penuh / masa pembukaan selesai — situs otomatis kembali ke tampilan "tutup" seperti semula. Mengganti REGISTRATION_FORM_URL TIDAK perlu redeploy, dan TIDAK perlu menunggu REGISTRATION_OPEN = TRUE dulu.

Belum pernah setup sama sekali? Sheet-nya perlu dibuat dulu satu kali (lihat komentar SETTINGS_SHEET_ID di config.js) — hubungi Tech PBJ kalau tombol di atas masih tampak nonaktif/abu-abu.

Cara ganti nomor WhatsApp Admin (2 kontak)

Website sekarang menampilkan DUA nomor WA admin sekaligus (bukan cuma satu), disimpan di tab "Config" — tab TERSEMBUNYI di spreadsheet yang sama dengan tab Registration/Event/Galeri (sengaja disembunyikan supaya tidak sengaja ke-edit orang lain yang dibagikan akses ke tab lain).

Kalau tombol di atas membuka spreadsheet tapi tab "Config" tidak kelihatan di baris tab paling bawah: klik ikon ☰ di pojok kiri bawah spreadsheet → pilih Config untuk memunculkannya sementara.

Kolom Sheet-nya Key | Value 1 | Value 2 — Value 1 = admin 1, Value 2 = admin 2. Cukup 2 BARIS saja (bukan 4), supaya tidak bingung dengan key berakhiran "_2":

Key (JANGAN diubah)Value 1 (admin 1)Value 2 (admin 2)
ADMIN_WA_NAMENama admin 1, mis. ArifNama admin 2, mis. Bastian
ADMIN_WA_NUMBERNomor WA admin 1. Format: kode negara + nomor TANPA angka 0 di depan (mis. 628123456789, BUKAN 08123456789)Nomor WA admin 2, format sama

Nomor admin 1 (kolom Value 1 di baris ADMIN_WA_NUMBER) JUGA yang otomatis dipakai saat calon member submit Form Pendaftaran di beranda (proses otomatis, tidak bisa menawarkan 2 pilihan).

Perubahan tampil di semua tombol/teks WA di website (footer, FAQ, halaman bantuan pendaftaran) dalam beberapa menit, TIDAK perlu redeploy. Kalau kolom Value 2 belum diisi di Sheet, website otomatis pakai nomor admin 2 cadangan dari kode (bukan tampak rusak/kosong). Kalau tab "Config" belum pernah dibuat sama sekali, tombol di atas akan tampak nonaktif — lihat panduan lengkap di docs/PANDUAN-ADMIN.md Bagian J.

Panduan setup awal (bikin folder Drive, API key, dsb.) ada di docs/PANDUAN-ADMIN.md dan komentar file config.js — biasanya sudah tidak perlu disentuh lagi sehari-hari.
